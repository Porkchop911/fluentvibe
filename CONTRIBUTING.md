# Contributing

fluentvibe is currently open for technical feedback, not general code
contributions.

Please use issues or discussion threads to report:

- API design feedback from real FluentControl or lab automation workflows.
- Missing commands, deck layouts, labware families, or liquid-handling cases.
- Simulator checks that are wrong, too strict, or missing.
- Documentation gaps that make the project hard to evaluate.

Because the project does not yet have an open-source license, do not submit
large patches or copied code until licensing and provenance are settled. Small
bug reports, minimal reproductions, and review comments are welcome.
